# LEIZEAK WEB

Aplicación web desarrollada para centralizar la información del grupo musical Leizeak en una única plataforma accesible para sus seguidores.



## Tecnologías utilizadas

* Next.js
* React
* Tailwind CSS
* Supabase (base de datos, autenticación y almacenamiento)
* Vercel (despliegue)



## Funcionalidades

* Visualización de conciertos
* Sección de noticias
* Apartado de productos
* Registro e inicio de sesión de usuarios
* Comentarios en noticias (usuarios registrados)
* Opiniones en productos (usuarios registrados)
* Formulario de contacto (usuarios registrados)
